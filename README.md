# Temporal-Tic-Tac-Toe
The game is a small variant derived from standard Tic-Tac-Toe. The rules are as follows:

1. The game is played on a 3×3 board. A player wins by getting three pieces in a row; however, each player can only have **three pieces on the board at a time**.
2. After all three of your pieces are placed, before placing a new piece, **the earliest piece you placed will disappear**.
3. You cannot place a piece on the position where the piece **just disappeared**.
4. The starting player is randomized

The website has two modes to play with:
1. Play with a bot
   * with an option to defeat bot with a helper (analyze the possibilities to win when placing a piece,  based on 100 Monte Carlo simulations per cell)
2. Play with your friend (Local Multiplayer)

Tech Stack: 
- Frontend:
  - Core Library: React
  - Language: TypeScript (for strict state management and API payload typing)
  - Environment: Local Development (Vite)
- Backend (API Gateway):
  - Runtime: Node.js
  - Framework: Express.js
  - Language: TypeScript
  - Environment: Local Development (localhost:5000)
- Bot Algorithm Service:
  - Language: Python
  - Framework: FastAPI
  - Libraries: Standard Python libraries (`random`) and `pydantic` (for data validation)
  - Logic: Custom heuristic evaluation combined with a Monte Carlo simulation engine.
  - Environment: Local Development (localhost:8000)
- Communication:
  - Protocol: HTTP
  - Architecture Standard: REST
  - Data Format: JSON for all request and response payloads
  - Security/Routing: CORS configured on both backends to accept cross-origin requests from the local React dev server.
- APIs:
  - Internal API: Node.js securely communicating with the Python bot service (Server-to-Server).
  - External API: React frontend communicating with the Node.js API Gateway (Client-to-Server).
  - Documentation: Swagger / OpenAPI UI (auto-generated by FastAPI) available at `http://localhost:8000/docs` to test endpoints and view request/response schemas.
