# Temporal-Tic-Tac-Toe

🎮 **[Play the Game Here!](https://temporal-tic-tac-toe.vercel.app/)**

Temporal Tic-Tac-Toe is a strategic variant derived from the classic game, adding a sliding window of historical moves to create dynamic, continuously evolving gameplay.

## Rules
1. The game is played on a standard 3×3 board. A player wins by getting three pieces in a row.
2. **The Catch:** Each player can only have **three pieces on the board at a time**.
3. **Temporal Decay:** After all three of your pieces are placed, before you can place a new piece, **your earliest placed piece will disappear**.
4. **The Dead Zone:** You cannot place a piece on the exact position where a piece **just disappeared** on that same turn.
5. The starting player is randomized each game.

## Game Modes
1. **Play with a Bot:** Challenge a custom heuristic AI.
   * *Assist Mode:* Toggle on an integrated helper that calculates your exact Win Probability for every available square, powered by a 100-round Monte Carlo simulation engine.
2. **Play with your Friend:** Pass-and-play local multiplayer.

## Tech Stack: 
- Frontend:
  - Core Library: React
  - Language: TypeScript (for strict state management and API payload typing)
  - Hosting: Vercel
- Backend (API Gateway):
  - Runtime: Node.js
  - Framework: Express.js
  - Language: TypeScript
  - Hosting: Render
- Bot Algorithm Service:
  - Language: Python
  - Framework: FastAPI
  - Libraries: Standard Python libraries (`random`) and `pydantic` (for data validation)
  - Logic: Custom heuristic evaluation combined with a Monte Carlo simulation engine.
  - Hosting: Render
- Communication:
  - Protocol: HTTP
  - Architecture Standard: REST
  - Data Format: JSON for all request and response payloads
  - Security/Routing: CORS is strictly configured on both backends to only accept cross-origin requests from the production Vercel frontend URL.
- APIs:
  - Internal API: Node.js securely communicating with the Python bot service (Server-to-Server).
  - External API: React frontend communicating with the Node.js API Gateway (Client-to-Server).
  - Documentation: Swagger / OpenAPI UI (auto-generated by FastAPI) available at `https://temporal-tic-tac-toe.onrender.com/docs` to test endpoints and view request/response schemas.

## A Note on Cloud Performance
Because the backend microservices are deployed using Render's free tier, the servers will automatically "spin down" (go to sleep) after 15 minutes of inactivity to save resources. If you are the first person to play the game in a while, the bot's very first move may take up to 50 seconds to process while the cloud servers wake up. Once awake, all subsequent moves and Monte Carlo simulations will execute in milliseconds.
