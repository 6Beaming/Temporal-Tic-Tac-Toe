# Temporal-Tic-Tac-Toe
The game is a small variant derived from standard Tic-Tac-Toe. The rules are as follows:

1. The game is played on a 3×3 board. A player wins by forming a straight line of their pieces.
2. After a player places a piece, any piece that was placed more than 3 moves ago will disappear.
3. Players are not allowed to place a piece on a position where a piece has disappeared.
